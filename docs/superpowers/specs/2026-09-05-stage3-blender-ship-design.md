# Этап 3: пайплайн Blender и корабль игрока — дизайн

Дата: 2026-09-05. Статус: утверждён владельцем. Основа: спека
`2026-09-04-space-rail-shooter-design.md`, разделы 5 и 7, плейтест
`docs/playtests/2026-09-04-greybox.md`, концепт
`art/refs/concept-ship-beetle-main.png`.

## 1. Цель

Модель корабля игрока «Жук» из Blender заменяет капсулу в игре. Пайплайн
«скрипт → .blend → .glb → Godot → скриншот» отлажен и задокументирован, чтобы
этап 4 (враги, астероид) шёл по нему без раздумий.

## 2. Решения этапа

| Вопрос | Решение | Почему |
|---|---|---|
| Как управлять Blender | Python API headless: `blender -b --python script.py`. Без MCP | Меньше движущихся частей, воспроизводимо, скрипты в репозитории. MCP при необходимости позже |
| Концепт | «Жук»: пухлый корпус, одно сопло с циановым кольцом, купол кокпита, два жёлтых бластера-усика, маленькие крылышки. Акцент оранжевый | Выбор владельца, концепт Codex с provenance в `art/refs/` |
| Ось носа | Blender **+Y** → Godot −Z | Проверено экспортом тестовой стрелки |
| Материалы | Два материала на одну палитру: `palette` (базовый цвет) и `palette_emit` (эмиссия, сила 3) | Один материал не даёт эмиссии только части ячеек без лишних масок |
| Раскраска | UV каждой грани схлопнуты в центр ячейки палитры 8×8 | Плоский цвет без развёртки, стиль референсов |
| Превью | Скриншот из Godot через `game/tools/screenshot.gd`. Рендер из Blender как дополнение, если EEVEE работает headless | Godot-кадр это и есть критерий приёмки |
| Коллайдер игрока | Остаётся капсула 0.6×3.0 | Меньше визуала, прощает игроку касания. Пересмотр на этапе баланса |

## 3. Файлы

```
art/
├── blender/
│   ├── lib/
│   │   ├── __init__.py
│   │   ├── palette.py      # цвета, ячейки, генерация palette.png (без PIL, через bpy.data.images)
│   │   ├── materials.py    # ensure_palette_materials(): 'palette' и 'palette_emit'
│   │   ├── build.py        # bmesh-хелперы: примитивы с трансформом, покраска граней в ячейку, сборка объекта, auto smooth
│   │   ├── export.py       # save_blend(), export_glb()
│   │   └── preview.py      # render_views(): три ракурса в PNG, опционально
│   ├── scripts/
│   │   ├── make_palette.py # → art/blender/palette.png и game/assets/textures/palette.png
│   │   └── ship.py         # → art/blender/ship.blend, game/assets/models/ship.glb, art/refs/preview-ship-*.png
│   └── palette.png
├── export.py               # переэкспорт всех .blend после ручных правок
├── check_models.py         # проверка .glb по style-guide, код возврата 1 при нарушении
└── tests/
    └── test_palette.py     # unittest без bpy: координаты ячеек, список цветов
scripts/
└── art.sh                  # make-palette | ship | export | check | import | shot
```

Godot: `game/assets/textures/palette.png`, `game/assets/models/ship.glb` плюс
их `.import`. Код игры не меняется: `ModelSlot` уже подменяет заглушку.

| 3 | Оружие матовое | (0) жёлтый #FFD23F |

`Nearest` не требуется, потому что UV сидят в центрах ячеек.

## 5. Геометрия корабля

Корпус 3.4 м по Y, с усиками 4.3 м; ширина с крылышками 3.4 м; высота с
кокпитом 1.9 м. Пивот в центре корпуса. Цель 450–700 треугольников.

| Часть | Примитив | Размер и позиция | Цвет |
|---|---|---|---|
| Корпус | UV-сфера 12×8, масштаб (1.1, 1.7, 0.8) | центр (0,0,0) | кремовый; грани с центром 0.1 < y < 0.6 оранжевые (поперечная полоса); грани с z < −0.35 тёмно-синие |
| Сопло | Цилиндр 12 сегментов, r 0.75, глубина 0.5 | (0, −1.65, 0) | тёмно-синий, задняя крышка циан эмиссия |
| Ядро сопла | Цилиндр 12, r 0.35, глубина 0.2 | (0, −1.95, 0) | почти чёрный |
| Кокпит | UV-сфера 8×6, масштаб (0.45, 0.5, 0.35) | (0, 0.5, 0.75) | тёмно-синий, одна верхняя передняя грань белая |
| Крылья ×2 | Два куба: внутренний (0.6, 0.5, 0.08) в (±1.1, −0.9, −0.1), внешний (0.3, 0.5, 0.08) в (±1.55, −0.9, −0.1) | | внутренний кремовый, внешний оранжевый |
| Бластеры ×2 | Цилиндр 8, r 0.06, глубина 0.8 | (±0.45, 1.85, 0.15) | жёлтый |
| Основания бластеров ×2 | Цилиндр 8, r 0.12, глубина 0.25 | (±0.45, 1.5, 0.15) | тёмно-синий |

Всё объединяется в один объект `ship` с одним мешем `ship`, shade smooth by
angle 30°, трансформации применены.

## 6. Проверки

- `python -m unittest discover -s art/tests`: ячейка → UV, нет дубликатов
  цветов, все hex валидны.
- `art/check_models.py` через Blender headless: импортирует `ship.glb`
  обратно, проверяет один меш, 450–800 треугольников и габариты в осях
  Blender: ширина X 3.0–3.8, длина Y 4.0–4.6, высота Z 1.6–2.2.
- Godot: `--import` без ошибок, headless-прогон без `ERROR`, предупреждение
  `ModelSlot: ship.glb не найден` исчезает, скриншот `docs/playtests/shot-ship.png`
  показывает корабль носом от камеры, освещённый сверху, с кольцом сопла к
  зрителю.
- Владелец смотрит скриншот и игру: решение CONTINUE или ADJUST.

## 7. Вне этапа
